## Design Context

### 适用范围

仅适用于 DeepSeek 余额查询插件的自动播报和手动查询。

### 用户与场景

ZCode 中直连 DeepSeek 官方 API 的用户，需要了解账户余额，及时发现余额不足。

### 文案与呈现

- 沿用本仓库状态行样式：行内代码品牌标签、加粗总余额、与正文空一行。
- 总余额优先，随后是充值余额与赠金；用 ¥ 和 US$ 区分币种，不换汇或合并。
- 高于阈值显示 🟢；达到或低于阈值显示 🔴 并明确写出“低余额”及阈值，不仅依赖颜色。
- 不可调用时明确提示；缺失金额显示 `—`，不猜测为零。
- 最终回复必须保留完整正文，不能只剩余额。中途提醒后继续任务。

阈值、精度、凭据及接口口径以 [README](README.md) 为准。
